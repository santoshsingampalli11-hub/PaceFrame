# Fast-bowling V1

B.Tech capstone prototype: analyze **standardized side-on smartphone video** of cricket fast bowling and extract a small set of scientifically defensible **2D** kinematic measurements.

This is not laboratory motion capture. The analysis pipeline must be proven before the web app is built.

## Current status

Project rules are in `.cursor/rules/`. Next: prove that standardized bowling videos can be processed reliably (pose + quality checks), then validate measurements, then build the web app.
